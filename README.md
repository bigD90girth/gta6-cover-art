Vice Cover — turn your photos into GTA-style cover art.
## Run it
```sh
node serve.ts
```
Then open http://localhost:8080. Pick a layout (Hero, Trio, Duo), drop a photo into each panel — upload your own or use a sample — drag to position, zoom, flip, write a caption, and export the PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080.
